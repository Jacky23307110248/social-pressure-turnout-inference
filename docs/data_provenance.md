# Data provenance

The project uses real administrative voter records archived by the Yale Institution for Social and Policy Studies. The persistent dataset identifier is `10.60600/YU/CGMWNW`, and the exact public file identifier is `42238`.

The access endpoint is `https://dataverse.yale.edu/api/access/datafile/42238`. The downloaded tab-separated table has 344,084 voter rows, 180,002 households, 10,000 assignment blocks, and 16 columns. Its verified response size is 20,061,989 bytes and its SHA-256 is `05807BCBEDAACF02EC6E6838E1B9C9B2FC99AD9D8C63F80C162991970044C6CE`.

Yale Dataverse marks the dataset CC0 1.0 and the file unrestricted. The repository does not redistribute the raw person-level table; reproducibility is provided through a verified download step.
