# Data access

Raw data are intentionally excluded from version control. Running `scripts/run_primary_analysis.py` downloads Yale Dataverse file `42238`, verifies the response against the expected SHA-256, and writes it to `data/raw/`.

Dataset DOI: `10.60600/YU/CGMWNW`

License: CC0 1.0

Expected access-response SHA-256: `05807BCBEDAACF02EC6E6838E1B9C9B2FC99AD9D8C63F80C162991970044C6CE`

The analytical table contains coded voter attributes and administrative turnout outcomes. It does not contain names, street addresses, email addresses, or telephone numbers. Even though redistribution is permitted, download-on-demand avoids unnecessary duplication of person-level records.
